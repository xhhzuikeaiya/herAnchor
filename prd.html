🎯 1. 产品概述

1.1 一句话定位

Product Positioning

ShadowSpeak 是专为留学生设计的中文口语精准训练官——AI 实时告诉你哪个字、哪个声调、哪里发错了，通过影子跟读闭环和发音错题本，让中文口语从「能说」进化到「说准」。

1.2 核心问题

  • 发音反馈缺失：Duolingo / HelloChinese 的发音评分仅给总分，无法告知声调 / 声母 / 韵母具体偏差，学生不知如何改进。
  • 跟读流程不完整：市面所有产品仅停留在「播放 → 录音」两步，缺少对比分析、错误归因和复习闭环。
  • 错误积累无管理：没有产品将发音错误纳入间隔复习（Spaced Repetition）系统，学生反复犯相同错误。

1.3 MVP 目标

MVP Definition

在 6 个月内交付可验证 PMF 的最小功能集：影子跟读完整工作流 + 声调级 AI 发音纠错 + 发音错题本，完成 5 所大学 Beta 试点，DAU ≥ 500，次日留存 ≥ 45%。

📝 4. 用户故事 & 验收标准

4.1 影子跟读工作流 P0

US-001
选择素材并调整跟读速度
P0
作为一名留学生，我希望从素材库中选择合适的课文，并按 0.5× / 0.75× / 1.0× / 1.25× 调整播放速度，以便在跟读初期降速，逐步提升。
  • ✓素材库按 HSK 等级（1–4）分类展示，每级 ≥ 50 条素材
  • ✓支持 4 档速度切换（0.5× / 0.75× / 1.0× / 1.25×），切换即时生效
  • ✓可切换到「逐句模式」：自动在每句末尾暂停，等待用户跟读
  • ✓素材含原文汉字 + 拼音 + 英文译文，三者可分别显示/隐藏
US-002
录音并获取即时波形对比
P0
作为一名留学生，当我跟读一句话后，我希望立即看到我的录音与原声波形的可视化对比，以便直观判断语调走势是否一致。
  • ✓范读波形（蓝紫）与用户录音波形（红）叠加对比展示
  • ✓吻合部分标绿，偏差部分保持红色，偏差超过阈值则高亮
  • ✓录音延迟 ≤ 100ms 开始波形渲染，分析结果 ≤ 2s 返回
  • ✓用户可点击播放自己录音和范读做主观对比

4.2 声调级 AI 发音纠错 P0

US-003
逐字发音分析与可解释错误反馈
P0
作为一名留学生，录音结束后我希望看到每个字的发音评分，并对错误字音获得「发第几声→实际发成第几声」级别的具体反馈，而不只是一个总分数。
  • ✓逐字展示发音结果：正确（绿）/ 偏差（黄）/ 错误（红）
  • ✓错误类型归因至：声调错误 / 声母错误 / 韵母错误 / 连读错误
  • ✓错误字显示「应发 X 声 → 实际发成 Y 声」的明确描述
  • ✓提供简短纠正建议（≤ 40 字），如「第3声需先降后升，尾部上扬」
  • ✓声调准确率评测精度（与人工标注对比）≥ 85% Accuracy
US-004
总体发音评分 & 历史趋势
P0
作为一名留学生，我希望每次练习后获得 0–100 总分，并查看近 7 天的分数趋势，以便感受到进步并保持动力。
  • ✓每次发音返回 0–100 综合评分，细分：声调 / 声母 / 韵母 / 流畅度
  • ✓首页展示 7 日发音趋势折线图（按声调/综合可切换）
  • ✓每次超过个人历史最高分时展示「新纪录」动效

4.3 发音错题本 P0

US-005
错误字音自动收录 & 间隔复习
P0
作为一名留学生，我希望发音错误的字自动或手动加入错题本，并根据艾宾浩斯曲线在最佳时间提醒我复习，以解决反复犯同样错误的问题。
  • ✓发音评分 ≤ 60 分的字自动提示「加入错题本」，用户一键确认
  • ✓错题本按「今日到期 / 声调错 / 声母错 / 已掌握」分类展示
  • ✓间隔复习算法：错误后 1天 → 3天 → 7天 → 14天 → 30天推送
  • ✓复习会话：听范读 → 跟读 → AI 评分，得分 ≥ 80 则标记「掌握」
  • ✓每日推送通知（可关闭）：「你有 N 个音节今日需复习」
  • ✓掌握程度可视化（进度条 0–100%）

4.4 HSKK 朗读模拟 P1

US-006
HSKK 朗读题型模拟练习
P1
作为 HSKK 备考生，我希望在模拟真实考场环境（准备时间 + 录音倒计时）下练习朗读题，并获得对应 HSKK 评分标准的 AI 反馈。
  • ✓题库含 ≥ 100 道 HSKK 朗读真题（初/中/高级各 ≥ 30 题）
  • ✓准备时间 20s + 录音时间 40s，倒计时视觉提示
  • ✓AI 评分对标 HSKK 四维：发音准确度 / 声调 / 流畅度 / 综合
  • ✓支持模拟全套（10题）连续练习，结束后输出总报告

🔁 5. 核心 UX 流程

5.1 影子跟读主流程

主流程（Happy Path）

首页 → 选素材（HSK等级+场景）→ 设置跟读速度 → 收听范读 → 逐句录音 → 查看波形对比 → 点击错误字 → 查看声调归因 + 纠正建议 → 一键加入错题本 → 下一句循环 → 课程结束页（总评分 + 本次新增错题数）

5.2 错题本复习流程

每日复习（Spaced Repetition Loop）

通知推送「N 个音节今日复习」→ 进入错题本 → 按到期排序 → 点击字音 → 听范读 3 遍 → 跟读录音 → AI 评分 → ≥80 分标记掌握（绿）/ <80 分延迟复习 → 批次结束显示复习成果

5.3 关键交互约束

  • 录音权限请求：首次进入跟读页时，一次性申请麦克风权限，配合清晰说明文案（「ShadowSpeak 需要麦克风来分析你的发音」）
  • 离线降级：无网时可播放已缓存素材并录音，联网后上传分析；不支持离线 AI 评分（需明确提示）
  • 隐私：录音仅用于本次评分，不永久存储服务端（除非用户主动保存），符合 GDPR

⚠️ 8. 风险 & TBD

风险等级影响缓解方案
发音评测精度不足（最高风险） 🔴 高 核心价值主张崩塌，用户失信 Pre-MVP：用 100 条真实录音验证讯飞 / Azure 精度，达标再上线；设置「反馈纠错」按钮收集误判数据
录音权限拒绝率高 🟡 中 核心功能无法使用 精心设计权限请求说明文案；iOS 遵循「just in time」权限申请最佳实践
素材版权问题 🟡 中 法律风险 MVP 使用 HSK 官方公开教材（CC 授权）+ 自制录音，避免第三方版权素材
冷启动：无内容即无用户 🟡 中 用户进入 App 无内容可练 上线前准备 ≥ 200 条 HSK 1–3 精选素材（专业发音教师录制）
API 成本随用户增长超预期 🟢 低 单位经济恶化 早期监控每用户 API 成本；单次评测控制在 $0.003 以内
